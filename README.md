# Práctica de Antropometría Ergonómica

Sitio académico con la resolución de tres ejercicios de diseño ergonómico para los percentiles 5.º al 95.º:

- Estación de trabajo sentada.
- Pupitre eléctrico infantil.
- Puesto para manejo de cargas.

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Compilación

```bash
pnpm build
```
